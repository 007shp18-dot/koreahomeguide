How the comparison works

KoreaHomeGuide checks similar contracts in the same district and property category, starting with the most recent completed months. It widens the size and deposit range only when there are too few comparable contracts.

A result can still miss floor, exact building condition, furnishings, maintenance fee, view, renovation status, or exact neighborhood differences. Treat it as a price check before you ask better questions—not as a valuation.
