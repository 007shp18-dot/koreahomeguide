# KoreaHomeGuide Real Prices v3

## Required Vercel environment variable

Name:
`DATA_GO_KR_SERVICE_KEY`

Value:
Your public data portal service key.

After adding the variable to Production, redeploy.

Supported official rental data in this build:
- Officetel rental transactions
- Villa / multi-family rental transactions

Apartment rental data can be added after confirming the current official endpoint/spec.
