# 서울·싱가포르·두바이 화면 통일 및 한국어 문구 정리

## 목표

기존 색상·브랜드·상위 5개 메뉴·URL을 유지하면서, 같은 기능은 어느 도시에서도 같은 순서와 모양으로 제공한다. 한국어는 영어 문장을 옮기는 대신 사용자가 하려는 일을 짧고 자연스럽게 설명한다.

대화에서 승인된 공통 구성에 개요(Overview)와 단지 상세 화면을 포함한다. 사용자는 이 문서의 방향을 승인했고, 기본 언어인 영어의 문구 검수도 명시적으로 추가했다. 이 문서는 구현 기준이며, 아직 코드 변경이나 배포를 뜻하지 않는다.

## 현재 확인된 문제

- 서울 개요는 `SeoulOverview`와 `MarketOverviewRows`, 한국어 싱가포르·두바이 개요는 `KoreanMarketOverview`를 사용해 구성과 정보 밀도가 다르다.
- 한국어 싱가포르·두바이 개요에는 한국어 탐색·비교 경로가 있는데도 영어로만 제공된다는 안내가 남아 있다.
- `MarketDetailShell`은 이미지가 없을 때 대표 수치를 상단과 요약에 중복 출력할 수 있다.
- 공통 상세 스타일에 여러 차례 덮어쓴 규칙이 있고, 긴 문구가 좁은 칸에 들어간다.
- ‘제안 가격의 위치’, ‘완료된 대상 기간’, ‘지원하는 의사결정’ 등의 직역 표현이 남아 있다.

## 공통 화면 구성

| 화면 | 표시 순서 | 정리 기준 |
| --- | --- | --- |
| 개요 | 도시명·한 줄 소개 → 주요 수치 → 탐색·가격 비교 → 시장 특성·출처 | 소개와 행동 안내를 반복하지 않는다. 주요 수치는 최대 4개로 제한한다. |
| 탐색 | 도시·거래 유형 → 검색·필터 → 결과·지도 | 필터 이름, 검색 위치, 결과 카드의 정보 순서를 통일한다. |
| 상세 | 단지명·위치 → 가격·거래 건수·집계 기간 → 거래 추이·내역 → 비교 조건·출처 | 대표 가격은 한 번만 강조한다. 다음 행동은 ‘매물 가격 비교’로 명확하게 표시한다. |
| 가격 비교 | 비교 대상·입력 → 결과 요약 → 비교 조건·주의점 | 긴 안내는 결과나 접기 영역으로 옮기고, 입력마다 필요한 단위와 조건만 남긴다. |

### 개요

- 도시 소개, 대표 이미지, 주요 수치, 행동 링크의 위치와 크기를 공유한다.
- ‘실거래가 탐색’과 ‘매물 가격 비교’를 기본 행동으로 둔다. 가이드·시장 분석은 보조 링크로 제공한다.
- 숫자에는 단위와 해당 집계 기간을 붙인다. 서로 다른 기간의 통계를 같은 기간인 것처럼 묶지 않는다.
- 자료가 없으면 0으로 표시하지 않고 해당 수치 대신 자료 상태를 설명한다.
- 기존 두바이 공식 연간·분기 통계와 차트는 기간을 명시한 보조 시장 자료로 유지한다.

### 단지·지역 상세

- 단지명, 주소, 주택 유형은 상단에 묶는다. 큰 제목에 부연 설명을 함께 넣지 않는다.
- 가격 요약에는 가격 기준, 통화·면적 단위, 거래 건수와 집계 기간을 가까이 배치한다.
- 기존 거래 추이와 거래 내역은 유지한다. 자료가 없는 차트를 임의의 값으로 채우지 않는다.
- 출처·계산 방식·제외 조건은 별도 영역에 모으되, 가격 해석에 필수적인 제한은 가격 옆에 남긴다.
- 이미지가 없으면 빈 이미지 칸이나 가격 중복 대신 정보 영역이 자연스럽게 너비를 사용한다.
- 단지 상세와 지역 상세는 같은 시각 체계를 쓰되, 페이지 제목과 비교 범위로 차이를 분명히 한다. 두바이 지역 통계를 개별 단지 가격으로 표시하지 않는다.

## 한국어 작성 기준

| 현재 표현 | 기본 정리 방향 |
| --- | --- |
| 제안 가격 / 제안 가격 검토 | 매물 가격 / 매물 가격 비교 |
| 제안 가격의 위치 | 비교 결과에 맞춰 ‘주변 거래와 비교’ 등으로 작성 |
| 완료된 대상 기간 | 집계 기간. 완료 월만 포함한다는 조건은 필요한 곳에 별도로 설명 |
| 지원하는 의사결정 | 할 수 있는 작업을 직접 표기: 실거래가 탐색, 매물 가격 비교 |
| 중위가격 | 중앙값. 처음 필요한 곳에서 ‘거래가격을 순서대로 놓았을 때 가운데 값’으로 설명 |
| P25–P75 | 거래가격 중간 50% 범위. 계산 기호는 상세 설명에서 유지 |

- 일괄 문자열 치환만으로 끝내지 않고 실제 문맥에서 다시 읽는다.
- 제목은 주제 하나, 버튼은 행동 하나, 설명은 핵심 문장 하나를 원칙으로 한다.
- 구입 자금 안내는 ‘구입 비용’, 행동 체크 항목은 ‘구입 전 확인사항’처럼 용도에 맞게 쓴다.
- 출처·신고 지연·표본 부족·세금 조건 등 의미를 바꾸는 정보를 짧게 만들기 위해 삭제하지 않는다.

## 기본 언어인 영어의 문구 검수

영어를 기준 화면으로 먼저 확인하고 한국어에도 같은 정보 순서와 의미를 적용한다. 영어를 한국어 문장의 역번역으로 만들지 않는다. 버튼·제목은 sentence case로 맞추고, 지명·URA·HDB·Ready·Off-Plan 등 고유 명칭은 유지한다.

현재 소스에서 확인된 수정 대상:

| 위치 | 현재 문구 | 수정 기준 또는 문구 |
| --- | --- | --- |
| 싱가포르 개요 | Current product depth | 방문자에게 필요 없는 내부 제품 등급 행을 삭제하고 실제 제공 자료로 설명 |
| 싱가포르 개요 | Supported decisions | Explore and compare |
| 싱가포르 개요 | Browse released segments and projects. | Explore neighbourhoods and developments. |
| 싱가포르 개요 | Compare against compatible released evidence. | Compare your asking price with similar transactions. |
| 공통 개요 | Evidence and decision readiness | What can you compare? |
| 공통 개요 | What is usable now | Where to go next |
| 공통 개요 | Open the detailed rows for the current publication boundary. | See sources and coverage below. 해당 출처 영역이 실제 있을 때만 표시 |
| 싱가포르 비교 | Completed window | Reporting period. 완료 월만 포함한다는 설명은 별도 유지 |
| 싱가포르 비교 | Offer position | Price percentile. 실제 출력이 백분위이므로 의미를 유지 |
| 도시별 비교 진입 | Check an offer / Check a price / Check an asking price | Compare an asking price로 통일 |
| 두바이 개요 | Dubai Market Overview | Dubai market overview |

‘Released evidence’, ‘release gate’, ‘publication boundary’, ‘operating gates’, ‘rights posture’ 같은 내부 운영 표현은 공개 화면에서 출처·집계 범위·자료 없음 상태를 직접 설명하는 문장으로 바꾼다. 내부 타입이나 상태값 자체를 바꾸지는 않는다.

두바이 개요의 ‘estimated gross yields’, ‘annual rents’, 지역 통계와 개별 주택 가격의 차이 등은 의미 있는 제한이므로 유지한다. 영어의 모든 단어를 짧게 만드는 것이 목표는 아니다.

추가 검수 항목:

- 매매·임대 비교 맥락에 맞는 price/rent 명칭, 계약 전 asking price와 이미 계약된 transaction price 구분.
- 영어 개요·탐색·단지/지역 상세·가격 비교의 버튼 명칭과 제목 대소문자 일관성.
- 가격 백분위의 설명과 영어 서수 표기. 모든 숫자에 일괄적으로 `th`를 붙이지 않는지 확인.
- 개발 단계·시스템 상태가 이용자에게 필요한 안내를 대신하고 있지 않은지 확인.
- 한국어와 영어 모두 긴 제목, 표 머리글, 가격 단위의 줄바꿈 검수.

## 타이포그래피와 반응형

- 동일한 역할의 제목·본문·보조 문구에 공통 크기·행간·간격을 적용한다.
- 한국어 본문 자간은 기본값을 사용하고, 좁은 칸에 맞추기 위한 과도한 음수 자간은 쓰지 않는다.
- 제목과 버튼이 길면 문구를 먼저 줄인다. 카드마다 폰트 크기를 다르게 줄여 해결하지 않는다.
- 본문은 자연스러운 어절 단위 줄바꿈을 우선한다. 금액과 단위는 읽을 수 있는 한 덩어리로 유지한다.
- 좁은 화면에서는 카드와 상세 보조 영역을 세로로 쌓는다. 표만 필요한 경우 독립적으로 가로 스크롤한다.
- 360px·390px·768px·1280px 너비에서 제목, 필터, 가격, 탭, 출처 영역의 넘침과 과도한 빈 공간을 확인한다.

## 구현 경계

- 개요의 공통 표시 컴포넌트는 소개, 수치, 행동 링크, 시장별 추가 설명을 받는다. 데이터 조회는 기존 도시별 코드에 둔다.
- 공통 상세 틀은 신원 정보, 가격 요약, 거래 내역, 출처, 선택적 이미지 슬롯을 유지·정리한다. 기존 상세 페이지가 이 틀을 사용할 수 있도록 맞춘다.
- 모든 언어에서 동일한 기능의 구조를 공유한다. 기본 언어인 영어와 한국어를 모두 문맥 단위로 검수하고 재작성한다.
- 통계 계산, 데이터 공급자, 저장소 스키마, SEO URL, 상위 메뉴 분류는 변경하지 않는다.
- 서울 전세·월세, 싱가포르 민간 주택·HDB, 두바이 Ready·Off-Plan 구분은 유지한다. 통화, 면적 기준, 임대료 기간도 유지한다.

## 검수 및 배포 기준

1. 현재 main과 차이를 확인하고 기존 사용자 작업을 보존한다.
2. 실제 컴포넌트 테스트로 가격 중복, 한국어 링크의 영어 이탈, 자료 없음 처리, 필수 단위·집계 기간 유지 여부를 검증한다.
3. 타입 검사, 린트, 관련 테스트 및 전체 회귀 테스트를 수행한다.
4. 세 도시의 개요·탐색·대표 상세·가격 비교를 비교 검수한다. 싱가포르는 민간 주택과 HDB를 각각 포함한다.
5. 화면 확인이 접근 권한이나 도구 제약으로 불가능하면 해당 검수를 통과했다고 주장하지 않는다.
6. 변경된 화면과 남은 제한을 명시하고, 승인된 배포 경로를 통해 반영한다.

## 문서 자체 검토

범위는 기존 화면의 표시 구조와 문구로 한정했다. 공통 모양과 시장별 데이터 의미를 구분했으며, 출처나 필수 제한을 삭제하는 요구는 없다. 신규 기능·커뮤니티·데이터 수집 작업은 포함하지 않는다.
