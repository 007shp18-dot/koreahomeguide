# v10.7 White-First Expandable UI Design

## Goal
Refresh KoreaHomeGuide into a clean, white-first, data-first product UI that feels trustworthy now and can absorb maps, reviews, personalization, and monetization later without becoming cluttered.

## Design principles
- White-first: page canvas is white; use soft gray only for grouping, not large decorative color blocks.
- Data-first: key numbers and the next action appear before long explanation.
- Modular: pages are composed from reusable visual modules instead of one-off card styling.
- One primary action per section.
- Expansion-safe: optional filters, secondary tools, and future features live in predictable slots rather than top-level clutter.
- Advertising-safe: reserve contextual monetization slots, but do not render real ads in v10.7.
- EN/ZH parity: layout and hierarchy stay consistent across English and Simplified Chinese.

## Visual system
- Canvas: #FFFFFF
- Subtle surface: #F8FAFC
- Primary text: #111827
- Secondary text: #64748B
- Borders: #E5E7EB
- Primary action: #2563EB
- Primary hover: #1D4ED8
- Positive/negative colors are reserved for meaningful market data only.
- Shadows are minimal and localized.
- Border radii are moderate, not pill-heavy.
- Spacing is more generous and typography hierarchy carries more of the visual weight.

## Navigation
Primary header contains only:
- Explore
- Rent Check
- Guides
- Language switch

Secondary tools such as brokerage/move-in calculators remain discoverable inside relevant flows and the Context Rail rather than competing in primary navigation.

## Page layout
Data-heavy desktop pages use a 12-column conceptual grid:
- Main content: 8 columns
- Context Rail: 4 columns

On smaller screens the rail stacks after the main content.

The Context Rail is a reusable area for:
- relevant next action
- related tool
- related guide
- future sponsored partner/ad slot

v10.7 includes structural placeholders for future monetization but displays only first-party modules. No ad-network code is added.

## Homepage
Hero:
- H1: Know the real price before you sign.
- concise explanation of official signed transaction data
- District / Property type / Monthly budget as default controls
- Deposit hidden in optional filters
- primary CTA: Check rents

Below hero, show three clear intents only:
1. Explore neighborhoods
2. Check a rent quote
3. Before you sign

Avoid dense data blocks above the fold.

## Explorer
- compact filter bar with Area / Property type / Monthly budget
- optional deposit under More filters
- results prioritize neighborhood cards
- cards are simple, mostly white, and the whole card is the primary navigation target
- secondary metrics remain visible but visually quieter

## Neighborhood / dynamic dong pages
Order:
1. title/location
2. 4 key metrics
3. rent-by-deposit / rent-by-size modules
4. buildings
5. recent contracts
6. SEO explanatory text at bottom
7. Context Rail on desktop

## Building pages
Above the fold:
- display name + Korean official name
- location/type
- 4 key metrics (rent, deposit, size, recent contracts)
- primary Rent Check CTA

Then modular sections for rent trend, recent contracts, sale/jeonse when available, and comparisons.
Context Rail is reserved for related neighborhood/tool/guide and future monetization.

## Rent Check
Keep the decision flow distraction-light:
- input card
- result verdict
- evidence/transactions
- related calculator/guide in context area after the core answer
- no future ad slot inside the verdict or directly between verdict and evidence

## Guides
Guide typography becomes white-first and editorial. Long-form pages may support future in-content monetization positions, but v10.7 renders only neutral reserved structure if needed; no ad code.

## Future slots
Use semantic classes/data attributes rather than vendor code:
- `.context-rail`
- `.context-module`
- `.ad-slot[data-slot="sidebar"]`
- `.ad-slot[data-slot="content"]`
- `.ad-slot[data-slot="guide"]`

Ad slots are hidden/empty in v10.7 so they do not affect the current reading experience.

## Non-goals
- No map implementation in v10.7.
- No reviews, favorites, alerts, login, or personalization.
- No actual ad network integration.
- No changes to MOLIT parsing, statistics, SEO routes, or sitemap behavior except markup/classes needed for layout.
