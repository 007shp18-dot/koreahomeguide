# UX Completion and Home Stage Entry Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete the approved UX polish and add a measurable four-stage homepage entry pilot in English and Simplified Chinese without breaking Rent Check, saved comparisons, SEO, or analytics contracts.

**Architecture:** Two small shared browser modules progressively enhance the existing district select and homepage stage links. Existing UI utilities continue to own localized Rent Check decisions, while runtime files only bind those models to preserved DOM IDs. Shared CSS and the dynamic SEO renderer receive the presentation work after behavior is covered by focused Node tests.

**Tech Stack:** Static HTML/CSS, browser JavaScript UMD modules, CommonJS server renderer, Node `node:test`, ImageMagick for one deterministic PNG asset, Vercel production.

**Spec:** `docs/superpowers/specs/2026-08-28-ux-ia-phase-1-2-design.md`

## Global Constraints

- Preserve existing Rent Check DOM IDs, API endpoints, request/response shapes, canonical URLs, hreflang, saved-quote storage, and existing GA4 events.
- English and Simplified Chinese must ship together.
- Keep `Saved` in the mobile bottom navigation and keep global navigation labels unchanged during the pilot.
- Do not create `/tools/settlement-timeline/`.
- Do not send quote values, saved-home labels, email addresses, or recent district history to analytics.
- No modal email capture, dark mode, gradients, animation system, listings, broker matching, accounts, or new Vercel function.
- Use test-first RED → GREEN cycles for every behavior change.
- Report local, GitHub main, and production deployment states separately.

- [ ] **Step 3: Implement the shared stage module**

```js
(function(root,factory){
  const api=factory();
  if(typeof module==='object'&&module.exports) module.exports=api;
  else root.KHGHomeStageEntry=api;
  if(root&&root.document){
    const start=()=>api.mount({ root,doc:root.document });
    root.document.readyState==='loading'
      ? root.document.addEventListener('DOMContentLoaded',start,{ once:true })
      : start();
  }
})(typeof globalThis!=='undefined'?globalThis:this,function(){
  const STORAGE_KEY='khg_home_stage_v1';
  const IDS=Object.freeze(['budget','looking','quote','signed']);
  function normalizedLanguage(language){ return language==='zh-CN'?'zh-CN':'en'; }
  function buildStageItems(language='en') {
    const zh=normalizedLanguage(language)==='zh-CN';
    return [
      { id:'budget',label:zh?'正在制定预算':'Setting a budget',href:`${zh?'/zh':''}/guides/rent-apartment-korea-foreigner/#budget` },
      { id:'looking',label:zh?'正在看房源':'Looking at listings',href:`${zh?'/zh':''}/explore/` },
      { id:'quote',label:zh?'已拿到报价':'Got a quote',href:'#rent-check' },
      { id:'signed',label:zh?'已签租约':'Signed the lease',href:`${zh?'/zh':''}/guides/rent-apartment-korea-foreigner/#move-in` }
    ];
  }
  function readStage(storage) {
    try { const value=storage&&storage.getItem(STORAGE_KEY); return IDS.includes(value)?value:''; }
    catch (_) { return ''; }
  }
  function writeStage(storage,value) {
    if(!IDS.includes(value)) return null;
    try { if(storage) storage.setItem(STORAGE_KEY,value); } catch (_) {}
    return value;
  }
  function buildStageEvent(stage,language) {
    if(!IDS.includes(stage)) return null;
    return { stage,language:normalizedLanguage(language) };
  }
  function mount({ root=globalThis,doc=root&&root.document,storage }={}) {
    const section=doc&&doc.querySelector('[data-home-stage-entry]');
    if(!section||section.dataset.stageMounted==='true') return null;
    section.dataset.stageMounted='true';
    const language=doc.documentElement&&doc.documentElement.lang==='zh-CN'?'zh-CN':'en';
    let targetStorage=storage;
    if(targetStorage===undefined){ try { targetStorage=root.localStorage; } catch (_) { targetStorage=null; } }
    const previous=readStage(targetStorage);
    const status=section.querySelector('[data-home-stage-return]');
    for(const link of section.querySelectorAll('[data-home-stage]')){
      const stage=String(link.dataset.homeStage||'');
      if(stage===previous){
        link.classList.add('is-return-stage');
        link.setAttribute('aria-current','step');
        if(status) status.textContent=language==='zh-CN'?`上次选择：${link.querySelector('strong').textContent}`:`Last selected: ${link.querySelector('strong').textContent}`;
      }
      link.addEventListener('click',()=>{
        if(!writeStage(targetStorage,stage)) return;
        const payload=buildStageEvent(stage,language);
        try { if(payload&&typeof root.gtag==='function') root.gtag('event','stage_selected',payload); } catch (_) {}
      });
    }
    return section;
  }
  return { STORAGE_KEY,STAGES:IDS,buildStageItems,readStage,writeStage,buildStageEvent,mount };
});
```
