## 콘텐츠

**독립 기사 30편, 한영 60개 주소**를 구현했습니다. 구매 여정 24편, 서울 동네 3편, 현지 이슈 3편입니다. 두바이 현지 이슈는 기존 관리비 차감 수익 분석 글을 재사용해 도시별 첫 이슈 4편을 연결했습니다.

뉴스룸의 대표 글, 여섯 단계 여정, 관련 글, 동네 비교, 현지 이슈와 전체 목록에서 새 기사로 이동합니다. 각 글은 출처·자료 확인일·목차·다음 행동을 제공합니다. 비용 모형은 가정과 제외 항목을 실제 거래 자료와 구분합니다.

## 검증과 배포 상태

- Next.js 운영 빌드 완료: 컴파일·타입 검사·2,980개 페이지 생성 통과.
- 변경 TypeScript 51개 파일 ESLint: 오류 0개. 기존 테스트 이미지 경고 1개.
- 독립 편집 검토: 한영 본문·출처 연결·가상 비용 산술 검토 완료.
- 전체 단위 검사 2,778건 통과, 기존 조건부 검사 50건 건너뜀. 이 중 전체 실데이터를 읽다가 시간 제한을 넘은 2건은 제한을 60초로 조정한 뒤 동일한 검증 항목으로 개별 재검사해 통과했습니다.
- 데스크톱·모바일 시각 검사와 운영 반영은 아직 완료하지 않았습니다.
- 사용자가 공개 GitHub 업로드와 운영 배포를 승인한 뒤 PR #248을 생성했습니다. 첫 커밋의 CI lint·typecheck·test·build·데이터 경계 검사가 통과했습니다. 브라우저 검사는 498건 통과, 기존 조건부 제외 26건, 실패 9건이었으며 메뉴 개수·메뉴 닫기 순서·HTML 제목 인코딩의 세 테스트 원인을 수정했습니다. 후속 커밋에서 전체 재검증합니다.
- 보호된 미리보기의 임시 접근 링크는 자동 승인 검토에서 거부되었습니다. 배포 보호를 변경하지 않고 기존 CI 브라우저 검사와 승인된 배포 후 공개 화면 확인을 사용합니다.
- 상세 요약은 확인된 기간 중앙값과 집계 범위를 표시합니다. 서울 미니 차트는 같은 전용면적의 공개 매매 기록이 3개월 이상, 각 월 5건 이상일 때만 실제 거래점으로 나타납니다. 최신 매매가·신고가·새 가격 지수를 추정하지 않습니다.
- 서울 요약·상세의 집중 단위 검사 89건과 해외 요약·선택 상태 검사 41건, web 타입 검사·대상 lint를 통과했습니다. CI는 synthetic ready 상세를 검증하며 새 exact-evidence 요약의 실제 배치는 운영 데이터가 연결된 공개 화면에서 추가 확인합니다.
