# 자료 수집 점검·일괄 검토·Tool 공유 현황

## 변경

`/admin/evidence/`에 수집 점검 필터(충족/정보 부족/기간 경과/중복 후보), 행 선택·현재 페이지·필터 전체 일괄 승인/반려, Tool 공유 데이터 탭을 추가한다. 기존 인증, 정정, 철회 및 건별 이력을 유지한다. 공개 페이지 반영과 자동 수집은 이번 범위에 포함하지 않는다.

새 정형 필드는 `address`, `housingType`, `conditions`, `billingPeriod`이며 기존 JSON 자료에 선택 필드로 추가한다. 미달 자료도 대기 상태로 저장하여 보완할 수 있으나 승인에는 수집 기준을 적용한다. 기존 자료는 읽기 시점에 분류하며 값·상태·이력을 자동으로 바꾸거나 삭제하지 않는다. DB 스키마 마이그레이션은 없다.

## 수집 기준

- 매매·임대·관리비: 주소 또는 지역+단지명으로 대상 식별.
- 매매·임대: 면적과 주택 유형 필수.
- 모든 항목: 양수 금액, 시장 통화, 관측일·유효기간, 출처 URL 및 거래·부과·서비스 조건 확인. 자유 입력 조건은 운영자가 원문과 대조해야 한다.
- 임대·관리비: 월간/연간 단위 또는 별도 부과 기간. 매매는 총액/㎡당 단위.
- 업체 요금·공식 수수료는 지역과 서비스 조건으로 식별하며 건물·면적을 요구하지 않는다.
- 임대 180일, 기타 365일 초과 또는 만료·미래 시점은 기간 경과. 이는 운영 검토 기준이며 역사적 자료의 오류 판정이 아니다.
- 중복 후보는 출처 ID·URL·분류·만료일을 제외한 정형 값의 정확한 일치로 판정한다. 유사 건물명이나 표기 차이까지 탐지하는 퍼지 매칭은 아니다.
- 자료와 출처 승인 여부는 별도다. 커뮤니티·미검증 제보는 승인되어도 정성 참고 전용.

## 일괄 처리

1. 필터 조회 후 행/현재 페이지(25건)/필터 전체 선택.
2. 승인 또는 반려·제외를 선택하고 3~240자 공통 사유 입력.
3. 처리 대상 확인에서 조회·처리 가능·제외 건수를 확인.
4. 확정하면 변경된 각 자료의 이력을 같은 SQL 문에서 기록.

선택 ID는 최대 100개, 필터 전체는 서버에서 조회한다. 철회와 이미 같은 상태인 자료를 제외한다. 승인에는 출처 승인 및 수집 기준을 요구한다. 미리보기 이후 대상·버전·출처 버전·처리 가능 여부가 바뀌면 충돌로 다시 확인해야 한다. 감사 이력 저장 실패 시 자료 변경도 롤백된다. 대량 철회 기능은 제공하지 않는다.

## Tool 탭

기존 동의 버전의 `user_scenario`/`product_research` 자료 중 90일 보관 기간 내 미만료 자료만 조회한다. 시장·도구 필터, 공유 건수, 가격·면적·결과별 분포, 최근 25건(UTC)을 표시한다. 사용자 해시·재시도 ID·시나리오 해시는 응답에서 제외한다. 사용자 삭제는 다음 조회에 반영한다. 공유 건수는 이용자 수나 신고 거래 수가 아니다.

## 검증

PGlite PostgreSQL에서 기준 필터, 승인 차단, 선택·필터 전체 처리, 충돌 시 무변경, 감사 실패 시 롤백, 중복·만료, Tool 집계·삭제·만료 제외와 식별값 비노출을 검증한다. API 인증·same-origin 테스트와 기존 관리자 렌더링 테스트 포함 58건 통과. TypeScript 통과, ESLint 오류 없음.

`EVIDENCE_TEST_PGLITE_MODULE=/tmp/evidence-test/node_modules/@electric-sql/pglite/dist/index.cjs pnpm test apps/web/test/evidence-bulk-research.test.ts`로 신규 PostgreSQL 테스트를 재현할 수 있다. PGlite 미설치 환경에서는 해당 DB 테스트가 명시적으로 건너뛰어진다.

`tests/e2e/evidence-admin-bulk.spec.ts`는 로컬 전용 합성 인증과 API 응답 fixture로 화면 필터·확인 전 무변경·확정 요청·Tool 분포·화면 넘침을 검증한다. 실제 SQL 검증과 별도이며 운영 자료에 쓰지 않는다. 이 작업 환경의 로컬 브라우저 설치/접속이 제한되어 원격 CI에서 브라우저 검증한다.
