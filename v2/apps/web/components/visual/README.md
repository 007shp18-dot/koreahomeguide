# Visual interface, 19 September 2026

The implementation follows the user-approved photographic mockups rather than the previous budget-led page skeleton. Code in this folder is original implementation using existing React/Next.js dependencies. No paid template code is copied.

Reference patterns inspected: Aceternity Apple Cards Carousel (photographic hierarchy and clear card actions), GetLayers (photographic introductions and asymmetric editorial placement), HyperUI (semantic input/detail/table layout), Magic UI Scroll Progress (reading progress), Skiper CssLink (short arrow and link feedback), and Shapefest (blue/clay visual language).

- https://ui.aceternity.com/components/apple-cards-carousel
- https://www.getlayers.ai/
- https://hyperui.dev/components/application/
- https://magicui.design/docs/components/scroll-progress
- https://skiper-ui.com/v1/skiper40
- https://shapefest.com/

The decorative blue-houses.webp is a crop of the generated original concept in the user conversation, reused at the user's request. It is NOT a real property photograph. City photos remain existing licensed assets; their credits are retained. No Shapefest preview or paid asset was downloaded.

MarketPulse reuses the checked-in September 2026 editorial monthly-report-data.ts. These are historical transaction counts for explicitly selected cohorts, not citywide prices. It provides actual monthly values, a zero-based axis, keyboard/touch selection and a plain HTML data table. TokyoBudgetChart uses the existing checked-in 2026Q1 anonymous condominium comparison groups; its range bars are not a time series or property valuation.
