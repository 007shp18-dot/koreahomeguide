# signedprice — 신뢰 기능 구현 명세 (v2 확정판)

이 문서는 `signedpricecontractdecisionplatformdesign.md`(11개 기능 초안)를 **법적 검토와 v2 코드베이스 실사를 거쳐 다시 쓴 것**입니다. 구현 에이전트는 초안이 아니라 **이 문서를 기준**으로 작업합니다.

## 0. 초안에서 반드시 고쳐야 할 것 5가지

구현 전에 아래를 인지하십시오. 초안을 그대로 따르면 빌드가 깨지거나 사실과 어긋납니다.

**0-1. 팔레트가 v2와 다릅니다.**
초안의 petrol `#1c4048` / `#b6bfbe` / accent `#e05024`는 v2에 존재하지 않습니다. `test/design-tokens.test.ts`가 정확한 hex를 검사하므로 초안 색상을 쓰면 **테스트가 실패**합니다. §2의 매핑표를 따르십시오.

**0-2. F01의 "백테스트 6개월 게이트"는 불필요합니다.**
초안은 오차율 열을 6개월 뒤에 렌더하라고 했지만, **walk-forward 4겹 채점 결과가 이미 있습니다** (서울 아파트 매매 191,067건 / 36개월 / MdAPE 8.2%, 겹별 7.5~9.5%). 지금 게시할 수 있습니다.

**0-3. F03은 현재 데이터로 계산할 수 없습니다.**
`data/signedvalue/*.json`은 (단지 × 평형 구간)당 `[건수, 앵커, 기준면적, 기준층]` 네 값만 담습니다. **p25/p75가 없습니다.** 데이터 파일 스키마를 바꾸지 않으면 F03은 불가능합니다.

**0-4. F06의 갱신 플래그는 검증되지 않았습니다.**
초안은 `Contract.isRenewal`이 "v1 모델에 이미 있음"이라고 단정합니다. 국토부 전월세 API 응답에 `갱신요구권사용` / `종전계약보증금` / `종전계약월세` 필드가 실제로 내려오는지 **먼저 확인**하고, 없으면 F06을 보류하십시오. 없는 필드를 가정한 구현 금지.

**0-5. F08의 데이터 출처가 하나 사라졌습니다.**
서울시 정비사업 데이터셋은 **2025년 12월 4일자로 제공 종료**되었습니다. 입주 예정 물량을 쓰려면 다른 공식 출처를 먼저 확보해야 합니다.

## 2. 시각 어휘 — v2 토큰 재매핑

**초안 색상을 쓰지 마십시오.** 아래로 치환합니다.

| 뜻 | 초안 | **v2에서 쓸 것** |
|---|---|---|
| 확정된 과거 실적 | petrol `#1c4048` | `var(--ink)` `#201e1d` |
| 확정이지만 분포 바깥 | `#b6bfbe` | `var(--muted)` `#5d5958` |
| 표본 부족 · 미완성 | 빗금 `#98978d/#f4f2ec` | 빗금 `repeating-linear-gradient(45deg, var(--muted) 0 2px, var(--surface) 2px 6px)` |
| 확정된 미래 | 외곽선 petrol | `border: 2px solid var(--ink); background: transparent` |
| 미탑재 시장 | 실선 1px | `border: 2px solid var(--line)` — **v2는 1px 구조선을 쓰지 않음** |
| 사용자 입력 · 주의 · 임계 초과 | accent `#e05024` | `var(--accent)` `#1d4ed8` |

**지켜야 할 제약 (테스트로 잠겨 있음)**

- `border-radius`는 항상 `var(--radius)` (= `0px`). 라운드 금지
- 구조선은 **2px**. `outline`은 **정확히 2px**, 색은 `var(--focus-ring)` 또는 `var(--ink)`만
- 새 hex 색 도입 금지. 토큰만 사용
- `fonts.googleapis.com` 참조 금지 (Archivo는 번들됨)
- `font-variant-numeric: tabular-nums`는 body 전역

**다크 배경 주의 (초안에 없던 실측 문제)**

```
--muted  #5d5958  on  --ink #201e1d  →  2.40 : 1   ✗ AA 미달
--accent #1d4ed8  on  --ink #201e1d  →  2.48 : 1   ✗ AA 미달
--canvas #f3f2f2  on  --ink #201e1d  →  14.86 : 1  ✓
```

**잉크 배경 위에서는 본문·라벨을 `var(--canvas)`로 쓰십시오.** 현재 홈의 "Phase 1 disclosure" 블록이 이 문제를 갖고 있습니다. `test/design-tokens.test.ts`의 `normalTextPairs`에 `['--muted','--ink']`를 추가해 재발을 막으십시오.

**빗금 규칙 (초안 유지)**

- 빗금은 **표본 부족·미완성**에만. 확정된 미래에 빗금 금지 — "믿지 마라"로 읽혀 논지가 뒤집힘
- 빗금·외곽선이 있는 모든 차트에 **2항목 이상 범례** 필수

## 3. 즉시 구현 (데이터 작업 없음)

### F07 · 정정 이력 `[S]` — **가장 먼저**

코드는 작지만 **시기를 놓치면 복구 불가**입니다. 오늘부터 쌓아야 합니다.

```ts
// lib/corrections.ts
export type CorrectionStatus = 'FIXED' | 'UPHELD';

export interface Correction {
  readonly id: string;
  readonly date: string;          // ISO date
  readonly scope: string;         // 영향받은 화면·구·단지
  readonly status: CorrectionStatus;
  readonly raisedBy: 'USER' | 'INTERNAL';
  readonly summary: string;       // 무엇이 틀렸고 어떻게 처리했는가
}
```

- 라우트: `app/kr/seoul/corrections/page.tsx`
- 저장: v1은 `lib/corrections.ts`의 정적 배열로 충분. DB 불필요
- 영향받은 화면에 `이 화면의 정정 이력 {n}건` 링크
- 상태 칩: `수정함` = `var(--accent)` / `유지함` = `var(--ink)`
- 하단 고정: `이의제기는 영업일 3일 안에 처리하고, 결과는 고쳤든 안 고쳤든 여기 남깁니다.`

**규칙 — `UPHELD`(고치지 않음)도 반드시 렌더한다.** 수정 건만 남기면 기록이 아니라 홍보입니다.

### F14 · 면책 문구 상단 이동 `[S]`

추정치 바로 아래에 배치합니다. 하단 각주 금지.

```
추정이지 감정평가가 아니며, 감정평가를 대신할 수 없습니다.
```

**카피 금지어 — 사이트 전체에서 `감정평가` / `감정가` / `평가액` 사용 금지.** 유일한 예외가 위 부정문입니다. 대체어는 **`추정가`**.

### F13 · 갱신일 도장 `[S]`

추정치가 나오는 모든 화면에 `데이터 기준 2026년 7월`. `data/signedvalue/index.json`의 `asOfMonth`에서 읽습니다.

### F02 · 사유가 붙은 빈 상태 `[S]`

```ts
export type EmptyReason =
  | { code: 'INSUFFICIENT'; n: number; threshold: number }
  | { code: 'NOT_REPORTABLE'; note: string }
  | { code: 'NOT_LOADED'; market: string };
```

| code | 제목 | 본문 | 다음 행동 |
|---|---|---|---|
| `INSUFFICIENT` | 계약이 부족합니다 | 이 조건의 최근 36개월 신고 계약이 {n}건입니다. 중앙값을 내면 한 건이 결과를 지배합니다. | 면적 조건을 넓히거나 같은 동의 다른 단지를 보세요. |
| `NOT_REPORTABLE` | 이 유형은 신고 대상이 아닙니다 | {note} | 이 구간은 앞으로도 채워지지 않습니다. |
| `NOT_LOADED` | 아직 적재하지 않았습니다 | {market}는 계약 원본 확보와 검증이 끝나지 않았습니다. | 검증 후 공개합니다. 임시 추정치는 넣지 않습니다. |

**규칙 — 빈 상태는 제목·사유·다음 행동 3요소를 반드시 갖는다.** 사유 없는 `—`는 고장으로 읽힙니다.

## 4. 데이터 작업이 따르는 것

### F01 · 자치구별 오차율 공개 `[M]` — **핵심 차별점**

국내에서 소비자 화면에 오차를 놓는 서비스는 없습니다. 이것이 브랜드입니다.

```
medianError(gu) = median( |estimate_T − actual| / actual )
                  학습 구간 이후 실제 신고 거래로만 채점 (walk-forward)
```

- 라우트: `app/kr/seoul/accuracy/page.tsx`
- 표 열: `자치구 / 신고 매매 건수 / 중앙값 오차 / 오차 10% 이내 비율`
- 색: `< 6%` `var(--ink)` / `6–10%` `var(--muted)` / `> 10%` `var(--accent)`
- 고정 문구: `계약이 적은 구일수록 오차가 큽니다. 숨기지 않고 같은 표에 둡니다.`

**금지 — 여기에 "가장 정확한" 류의 문구를 쓰지 마십시오.** 국내 상용 AVM의 공개 수치가 더 좋습니다(연구 논문 기준 MdAPE 3.2~4.9%). 우리가 파는 것은 정확도가 아니라 **정확도에 대한 정직함**입니다.

### F12 · PPE@10% 병기 `[S]`

MdAPE만으로는 국내 연구·경쟁 지표와 비교되지 않습니다. walk-forward 결과에서 바로 계산됩니다.

```
ppe10 = (|오차| ≤ 10% 인 거래 수) / (전체 채점 거래 수)
```

`signed-value.js`의 `ACCURACY`에 `ppe10Pct` 추가, F01 표에 열 추가.

### F03 · 중간 절반 폭 `[M]` — 데이터 스키마 변경 필요

`data/signedvalue/*.json`의 그룹 배열을 확장합니다.

```
현재:  [건수, 앵커만원, 기준면적, 기준층]
확장:  [건수, 앵커만원, 기준면적, 기준층, p25만원, p75만원]
```

기존 소비자(`signed-value.js`의 `estimate`)가 인덱스 0–3만 읽으므로 **뒤에 덧붙이면 하위 호환**됩니다.

```ts
const spreadRatio = (p75 - p25) / median;
const verdict = spreadRatio < 0.28 ? '좁음' : spreadRatio < 0.55 ? '보통' : '넓음';
```

| 판정 | 문구 |
|---|---|
| 좁음 | 중간 절반이 {폭} 안에 모여 있습니다. 단지 간 편차가 작아 이 숫자를 협상 근거로 쓸 만합니다. |
| 보통 | 중간 절반이 {폭}에 걸쳐 있습니다. 단지를 좁히면 더 선명해집니다. |
| 넓음 | 중간 절반이 {폭}에 걸쳐 있습니다. 구 단위 중앙값으로는 판단할 수 없으니 단지를 특정해야 합니다. |

### F04 · 최근 2개월 미완성 표시 `[S]`

신고 기한 30일 + 반영 지연 때문에 최근 구간은 계속 채워집니다.

- 판정: 오늘로부터 60일 이내 월 → `incomplete: true`
- UI: 해당 막대 빗금. 범례 2항목 필수 (`확정` / `신고 진행 중`)
- 문구: `최근 두 달은 신고 기한(30일)이 지나지 않아 계속 채워집니다. 낮아 보이는 것은 거래 감소가 아닙니다.`
- **미완성 월을 전월 대비 비교의 기준으로 쓰지 말 것**

### F09 · 문장 한 줄 입력 `[M]`

파싱 대상: 지역(구 25종 + 별칭) / 면적(㎡·평) / 거래유형(전세·월세·반전세·매매) / 금액(`7억 4천` → 74,000만원) / 주택유형.

- 읽은 항목은 `var(--ink)` 외곽선 칩, **못 읽은 항목은 `var(--accent)` 외곽선 + `못 읽음`**
- **못 읽은 항목을 추측해서 채우지 않는다.** 비워 두고 되묻는다
- 기존 입력 UI는 폴백으로 유지

### F11a · 실측 가격 영향 `[L]` — 사실 레이어와 분리

**우리 데이터로 계산되는 부분만 먼저 합니다.** 같은 단지·같은 전용면적 구간 안에서 해당 요인만 다른 계약 쌍의 중앙 프리미엄.

- 3열 표(사실 / 값 / 가격 영향), 영향은 `+/−N.N%`
- 쌍이 부족하면 `계약 부족`(회색) — **사실은 적고 영향만 비운다**
- 문구: `가격 영향은 같은 단지 안 계약 쌍에서 실측합니다. 쌍이 부족하면 사실만 적고 영향은 비웁니다.`

F11b(경사·일조·소음원 등 물리 사실 레이어)는 **공공 GIS에서 직접 산출할 때만** 착수합니다. §6 참조.

## 5. F10 대체 — 타사 후기 크롤링을 자체 수집으로

### 왜 원안을 폐기하는가

초안 F10은 "최근 2년 커뮤니티 글에서 단점 키워드 추출"입니다. 그 글이 타 서비스의 사용자 후기라면 세 축이 걸립니다.

- **저작권법 제93조** 데이터베이스제작자의 권리
- **정보통신망법** 접근권한 초과
- **부정경쟁방지법 제2조 제1호** 성과물 무단사용 ← 실질

대법원 2022.5.12. 선고 2021도1533(야놀자 v 여기어때)에서 **형사는 무죄**였지만 **민사에서는 성과물 무단사용 책임이 인정**되었습니다. 후기는 그 서비스의 핵심 자산이라 인용된 사건보다 조건이 나쁩니다.

**그리고 법 이전에 자기모순입니다.** 우리 포지션 전체가 "국토부에 신고된 공공 데이터만 쓴다"입니다.

### 대체 설계 — F10' 추정 검증 응답

단지 페이지 하단에 **자유게시판이 아닌 측정 도구**를 둡니다. 이 프레이밍이 콜드 스타트·모더레이션·조작을 동시에 해결합니다.

```
이 추정가({추정가}), 실제와 비슷한가요?
   ○ 더 높다    ○ 비슷하다    ○ 더 낮다

그렇게 보는 이유는? (선택)
   동·라인 차이 / 향 / 층 / 리모델링 / 조망 / 소음 / 기타
```

**이유 선택지는 우연이 아닙니다.** 우리가 페이지마다 "쓰지 못한 것"이라고 적어 둔 목록 그대로이고, 사용자가 답하는 내용이 정확히 우리 오차를 만든 성분입니다.

```ts
export interface EstimateFeedback {
  readonly buildingKey: string;   // gu|dong|building|band
  readonly direction: 'HIGHER' | 'SIMILAR' | 'LOWER';
  readonly reason: 'LINE' | 'ASPECT' | 'FLOOR' | 'REMODEL' | 'VIEW' | 'NOISE' | 'OTHER' | null;
  readonly createdAt: string;
}
```

**규칙**

- **집계만 노출.** 개별 응답 표시 금지
- **5건 이상부터 표시.** 미만은 질문만 렌더
- **기기당 1회.** 자유 텍스트 입력란 **없음** (v1에서는 절대 열지 말 것)
- 개인정보 수집 없음

**저장소 결정이 필요합니다.** 현재 v2는 정적 배포라 쓰기 저장소가 없습니다. 구현 에이전트는 임의로 DB를 도입하지 말고, **선택지와 트레이드오프를 제시한 뒤 승인을 받으십시오.**

## 6. 하드 룰 — 구현 에이전트가 어길 수 없는 것

1. **어떤 경쟁 서비스도 크롤링·스크레이핑하지 않는다.** 후기·시세·매물·이미지 전부. robots.txt가 허용해도 하지 않는다
2. **외부 데이터는 정식 공개 API 또는 공식 배포 파일로만 취득한다.** 건축물대장은 공공데이터포털, 싱가포르는 URA Data Service, 두바이는 Dubai Pulse
3. **경쟁 서비스명·중개사명을 화면에 쓰지 않는다**
4. **광고 호가와 신고 계약을 비교하지 않는다.** 계약 vs 계약
5. **`감정평가`·`감정가`·`평가액` 금지.** `추정가`만 사용
6. **"가장 정확한" 류 우위 주장 금지**
7. **없는 데이터를 평균으로 채우지 않는다.** 비우고 사유를 적는다
8. **예측 문구 금지.** `오를`·`내릴`·`전망`·`예상 가격` 사용 안 함
9. **API 키를 클라이언트 번들에 넣지 않는다.** 서버 라우트 경유만
10. **새 hex 색·라운드 모서리·1px 구조선을 도입하지 않는다**

## 8. 테스트 (`v2/apps/web/test/`)

기존 계약 테스트를 깨지 않는 것에 더해:

- **토큰 준수**: 신규 CSS에 `#` 리터럴 색이 없다. 모든 `border-radius`가 `var(--radius)`다. 모든 `outline`이 2px다
- **다크 대비**: `design-tokens.test.ts`의 `normalTextPairs`에 `['--muted','--ink']`가 있고 통과한다
- **금지어**: `app/`·`components/`·`lib/` 전체에서 `감정평가`가 나오는 곳은 면책 부정문 한 군데뿐이다
- **예측 문구 부재**: `오를`·`내릴`·`전망`·`예상 가격`이 없다
- **빗금 의미 단일성**: `repeating-linear-gradient` 사용처가 전부 "표본 부족·미완성"이다
- **범례 존재**: 빗금·외곽선 막대를 가진 모든 차트에 2항목 이상 범례가 렌더된다
- **빈 상태 3요소**: 모든 빈 상태에 제목·사유·다음 행동이 있다. `—`만 있는 셀은 실패
- **정정 UPHELD 표시**: `UPHELD` 항목도 목록에 렌더된다
- **응답 임계**: 응답 5건 미만이면 집계가 렌더되지 않는다
- **파싱 미추측**: 못 읽은 항목이 기본값으로 채워지지 않는다
- **미완성 월 제외**: 전월 대비 계산이 `incomplete: true`인 월을 기준으로 쓰지 않는다

## 9. 이 문서의 한계

- 여기 등장하는 **UI 수치·문구 예시는 실측값이 아닙니다.** 구현 시 실데이터로 대체하고, 데이터가 없으면 F02 빈 상태로 두십시오
- 참조한 해외·국내 서비스의 패턴은 공개 문서 기준이며, **기능·정보구조만 참고**했습니다. 문장·디자인 에셋·데이터는 가져오지 않았고, 가져와서도 안 됩니다
- 법적 판단 부분은 참고이며 법률 자문이 아닙니다. 유료화·B2B 전환 시점에는 별도 확인이 필요합니다
